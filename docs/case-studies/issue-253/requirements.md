## Not completed

These items are blocked. They are tracked upstream and are not presented as done.

- **The renamed `gh-upload-file` package cannot be adopted.** gh-upload-log was renamed upstream, but no release after 0.10.1 was published, because the npm publish of the new name fails with E404 (gh-upload-log#56). Fixing that needs the npm account owner. start keeps installing `gh-upload-log`, and its latest published release (0.10.1) supports everything start calls.
- **Four upstream defects stay open until their maintainers release fixes:** sensitive-data-sanitizer#50 and #51, link-cli#130, command-stream#235. None of them leaks a secret or loses data in start:
  - start does not send the input shapes that trigger #50 and #130 (record-scoped `key=value` strings are never bare numbers).
  - start imports command-stream lazily (#235).
  - #51 makes a log made of nothing but tokens slow, but it is still sanitized.
