## Research

- [Docker resource constraints](https://docs.docker.com/engine/containers/resource_constraints/): swap is a combined memory-plus-swap ceiling; matching memory and swap disables additional swap. CPU percentages must use daemon capacity.
- [Linux cgroup v2 memory files](https://docs.kernel.org/admin-guide/cgroup-v2.html#memory-interface-files): counters are cumulative, hierarchical, and count killed processes; historical counters do not establish why the main process later exited.
- Existing repository components: resource-limit HostConfig translation (#176), attempt lifecycle (#187), detached watcher, recovery delay, and cgroup sampling (#182) supply the integration points.
- Alternatives evaluated in [research](research.md): Hive Mind's pure CPU penalty state machine, Docker SDKs (`dockerode`/`bollard`), and file-lock libraries (`proper-lockfile`/`fs2`). Prefer existing Docker CLI and small shared-policy modules to avoid a new transport/dependency or incompatible lock format.
